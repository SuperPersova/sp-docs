# sp-docs

Public static documentation site for SuperPersova using MkDocs Material.

## Local Development

1. Install dependencies:
   - `pip install -r requirements.txt`
2. Serve locally:
   - `mkdocs serve`
3. Build static site:
   - `mkdocs build`

## Deploy

Use GitHub Pages with MkDocs deployment workflow or publish the built `site/` directory.
